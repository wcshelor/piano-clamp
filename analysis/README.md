# Generated analysis

This directory is the default analysis root. Common generated outputs include:

- `similarities/`
- `nearest_prompts/`
- `nearest_passages/`
- `reports/`
- `frozen_manifests/`
- `filtered_manifests/`

Typical producers are:

- `scripts/compute_similarities.py`
- `scripts/build_embedding_index.py`
- `scripts/validate_embeddings.py`
- `scripts/audit_study_readiness.py`
- `scripts/freeze_corpus_manifest.py`

The contents here are derived artifacts, not source data. Large generated files
are ignored by git.
